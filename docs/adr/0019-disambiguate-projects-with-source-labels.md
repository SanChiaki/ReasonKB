# Disambiguate projects with source labels

Project names preserve their source-native values and may repeat across Corpus Sources. Every source has a deployment-unique, editable Source Display Name, and every project selector, list, search result, and citation presents the Project name together with the source type and display name. Internal relationships use immutable source and Project IDs rather than display text. ReasonKB will not prefix or rewrite Project names merely to make them globally unique.
