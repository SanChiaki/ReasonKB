# Identify Seeyon collections by library and root

A manually registered Seeyon Source Collection is identified within its Corpus Source by the pair of document library ID and root archive ID, and duplicate pairs are rejected. Its display name is editable and does not affect collection, Project, document, or index identity. Changing either ID creates a new collection registration rather than mutating the old identity, preventing documents beneath different traversal roots from being merged into an existing Project.
