# Share source projects across the deployment

Projects created from Corpus Sources are shared retrieval scopes available to all deployment users rather than duplicated or owned per user. Only Source Administrators may create, configure, validate, enable, disable, deregister, synchronize, or purge source content, while ordinary users may select active Projects for retrieval. Per-user, department, and Project ACLs are outside the initial formal release, replacing the demo's hard-coded `owner_user_id` behavior with an explicit deployment-wide content boundary.
