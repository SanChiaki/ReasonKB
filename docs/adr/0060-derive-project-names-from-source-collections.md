# Derive project names from source collections

A Project's display name follows its Source Collection and is not independently editable; changing a registered collection's display name updates the Project label without changing identity or indexes. Same-named Projects from different Corpus Sources remain valid, and administration and retrieval selectors show the source display name and type alongside the Project name. All internal relationships use immutable Project IDs rather than display names, preventing labels from becoming identity or drifting away from their source collections.
