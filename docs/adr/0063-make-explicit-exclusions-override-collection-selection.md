# Make explicit exclusions override collection selection

Each Corpus Source may retain explicit exclusion rules for a whole Source Collection, a folder, or a document. Rules use the connector's stable external identity while keeping a display path only for administration, and they override every Collection Selection Policy, including `all`; consequently, a folder rule also excludes descendants discovered in future scans. Adding a rule immediately makes known matching documents non-retrievable, preserves their current indexes, supersedes queued index work, advances the affected Collection Filter Revision, and fences any synchronization that started under an older revision. Removing a rule does not immediately restore retrieval: an authoritative follow-up synchronization must confirm that the item is still present and visible, after which an unchanged source revision may reuse the retained index while a changed revision is reindexed. Connectors still report the directly excluded item, stop descending into an excluded folder, and treat its known descendants as seen so that exclusion is not mistaken for source deletion.
