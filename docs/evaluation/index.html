Implementation order

问题必须在丢失信息的阶段解决

P0索引源文本质量门禁

在建树前识别空页、控制字符、乱码、扫描件与表格结构异常；坏正文不能以 ready 状态污染后续索引。

P0PageIndex 树输出溢出

高密度编号正文会让结构化输出远大于输入。按输出预算分段、递归退避并保留页级树兜底，不能只提高 max_tokens。

P1路由与证据校验可观测

区分候选缺失、近似材料误选、校验误删和技术降级，让空 Evidence 能落到真实责任阶段。

P1自适应证据窗口

命中页面后按结构、表格跨度和未覆盖事项扩展相邻页，解决跨页步骤与表格续页丢失。

Method & boundary

报告怎样读，哪些内容没有公开

01 / PRIMARY METRIC

优先评估必需来源是否命中、原文是否可读、目标页面与事实锚点是否覆盖。Answer 仅作为附加 smoke test。

02 / SCALE

基线覆盖 616 份 ready 文档。扩容轨迹用于观察尾延迟，不把不同题量的阶段结果直接横向合并。

03 / VERSIONING

本公开摘要随代码版本提交，Git 历史保留每次快照。生成时间为 2026-08-12 15:31 CST，数据版本 evidence-first-natural-v2-100。

公开边界：原始审计报告包含受限语料的文件名、问题、页面内容和完整 Evidence，不适合发布到公开 GitHub Pages。本页保留方法、汇总指标、失败分类和改进方向；逐题证据审计继续在受控环境中进行。
