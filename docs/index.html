01 / WORKFLOW

从问题到可引用的 EvidenceSet

PageIndex 在文档内部沿树导航；ReasonKB 负责跨文档候选、证据落地、覆盖判断与访问范围。Answer 与 Evidence 共享同一条检索链，Answer 只在最后追加一次生成。

ROUTE

限定范围并选择候选

从授权 Project 中组合语义、全文和模型路由信号，保留可继续检索的候选文档。

NAVIGATE

进入文档树和页面

PageIndex 按问题判断相关节点，再读取对应页面内容；候选相关不等于证据成立。

GROUND

组成带出处的证据

逐份保留文档身份、页码、原始文本与结构化表格，拒绝无法落回来源的结论。

HAND OFF

交给 Agent 继续判断

返回支持项、未解决事项、置信度和停止原因；需要时再由 Answer 适配器生成答案。

Primary product object

Evidence 是主产品，不是答案生成的中间废料。

面向 Agent 的知识服务不能只交付一段看似完整的文字。调用方需要知道证据来自哪里、覆盖了问题的哪些部分、哪些事实仍未解决，以及本次检索是否因上游异常而降级。

PROVENANCEdocument + pages稳定的文档身份、来源路径与页面范围。
CONTENTexcerpt + content可快速扫描的摘录与可继续读取的原始证据。
COVERAGEaspects + unresolved已支持的原子事项和仍缺失的信息。
STATUSmatched | no_match | degraded区分业务无匹配与技术失败，避免静默空结果。
